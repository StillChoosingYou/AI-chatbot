Import students

Add many students at once from a CSV file (in Excel: File → Save As → CSV). One student per row, with these columns:

student_id full_name year_section status address contact_number

  • Student ID is the letter P and 9 digits, for example {{ student_id_example }}. Year & Section looks like 3E.
  • Status is Pending, Processing, For release or Released. Leave it empty for Pending.
  • Students who are already on the dashboard are skipped, never overwritten.
  • Up to {{ max_import_rows }} rows and {{ max_import_mb }} MB per file.
