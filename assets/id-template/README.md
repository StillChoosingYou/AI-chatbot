# PGPC layout assets

pgpc-header.png is only the school name, address, and institutional marks from the
upper 310 pixels of the supplied front-card reference. pgpc-campus.png is only the
building crop at x=230..950, y=340..555. Both were visually inspected; neither includes
a face, student identity, signature, contact number, or original QR code.

The full source card photographs are not bundled. Generated personal fields are
placeholders or the selected inventory record; the QR on the back is generated from
the app's own student link. A blank high-resolution PGPC template is needed for exact
campus artwork and typography: these isolated school crops retain the source blur.
